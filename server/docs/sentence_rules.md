# 세그먼트→문장 경계 규칙 (MVP)

## 목표

- VAD(무음≥1.2s)로 분절된 세그먼트를 **문장 단위**로 안정적으로 결합.
- TTS/평가 파이프라인에서 문장 단위가 기본이 되도록 표준화.

## 규칙 (요약)

1) **무음≥1.2s**는 문장 경계 후보.
2) 세그먼트 길이 < **0.8s** 이고, 다음 세그먼트와 간격 < **0.3s** 이면 **결합**.
3) 세그먼트 텍스트가 **구두점(.,?!:)로 끝나지 않으면** 다음 세그먼트와 **결합**(단, 총 길이 ≤ 10초).
4) “and, but, so, because, 그리고, 그런데, 그래서” 등 **연결어**로 끝나면 결합.
5) 문장 길이 상한 **10초** 초과 시 가장 가까운 **쉼표 근처**에서 강제 절단.

## 체크리스트

- 극저음 잡음 제거(100Hz HPF) 후 VAD 품질 확인
- 속삭임/작은 발화: `rms_thresh_dbfs`를 -50~-55로 낮춰 재시도
- 타이포/고유명사: `custom_words.json`에 추가 후 재실행
