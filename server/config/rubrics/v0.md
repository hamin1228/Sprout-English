# Rubrics v0 — Speaking & Writing

## Speaking (weights = 0.2 each)

- **WPM → wpm_score**: `(wpm - 70) / 70` clipped 0~1 (≥140 → 1.0)
- **Silence → silence_score**: `1 - silence_ratio / 0.35` clipped 0~1
- **Fillers → filler_score**: `1 - filler_per_min / 8` clipped 0~1
- **Grammar errors → grammar_score**: `1 - grammar_error_rate / 12` clipped 0~1 (per 100 tokens)
- **Cohesion (0~1)**

**Total** = weighted sum → **CEFR**:  
[0.00,0.25) A1 · [0.25,0.40) A2 · [0.40,0.55) B1 · [0.55,0.70) B2 · [0.70,0.85) C1 · [0.85,1.00] C2

## Writing (weights: grammar .35, lexical .20, cohesion .20, variety .10, task .15)

- **Grammar errors (per 100 words)** → `1 - x/10`
- **Lexical richness (0~1)**
- **Cohesion (0~1)**
- **Variety (0~1)**
- **Task fulfillment (0~1)**

Same CEFR mapping as Speaking.

## Notes

- v0는 **측정 가능성/자동화** 우선. 실제 모델 지표 연동 전까지는 앱이 추출한 지표를 입력으로 사용.
- B2 이상 목표 과제는 **총점 ≥ 0.70** 권고.
