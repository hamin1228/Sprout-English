# Tone Guides (MVP)

## polite-formal

**Do**
- Use polite requests: *Could you…*, *Would you mind…*
- Use *please*, *thank you*.
**Don't**
- Slang (*gonna, kinda*), abrupt imperatives.

**Example**
- Neutral → Polite-formal:  
  “Give me a latte.” → “Could I get a latte, please?”

## confident-formal

**Do**
- State strengths with evidence. Avoid hedging (*maybe, sort of*).
**Don't**
- Over-apology or self-deprecation.

**Example**
- Weak → Confident-formal:  
  “Maybe I can do it.” → “I can do it; I’ve done similar tasks successfully.”
